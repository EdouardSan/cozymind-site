# Product

## Register

brand

## Users

Visiteurs francophones curieux de CozyMind : futurs utilisateurs iPhone venus depuis le bouche-à-oreille ou l'App Store (lien « site web de l'éditeur »), et lecteurs des pages légales (politique de confidentialité, conditions d'utilisation) exigés par Apple et le RGPD. Contexte : visite courte, souvent sur mobile, le soir.

## Product Purpose

Site vitrine statique de l'application mobile CozyMind (suivi d'humeur, éditée par SND CAPITAL). Trois jobs : donner envie de télécharger l'app (badge App Store), rassurer sur la confidentialité (l'argument n°1 du produit : tout reste sur le téléphone), héberger les pages légales à une URL stable (cozymind.fr). Hébergé sur GitHub Pages, domaine cozymind.fr.

## Brand Personality

Douillet, honnête, apaisant. Le ton d'un rituel du soir : chaleureux sans être infantilisant, rassurant sans jargon. La mascotte nuage incarne la marque ; l'ambre est la couleur du foyer.

## Anti-references

- Le « wellness générique » : dégradés lavande/menthe, photos stock de méditation, promesses thérapeutiques.
- Les landings SaaS : grille de cards identiques, hero-metric, badges de logos, dark mode « tech ».
- Tout ce qui évoque le médical ou la performance (scores, courbes de productivité).

## Design Principles

- **Le site ressemble à l'app.** Mêmes tokens (crème #FAF6F0, encre #2E2A26, ambre #E9A94D, les 5 couleurs d'humeur), même douceur de rayons. Un utilisateur qui ouvre l'app après le site ne doit sentir aucune couture.
- **La confidentialité est un argument de vente, pas une page cachée.** Elle a sa place sur la landing, dite simplement.
- **Montrer l'app, pas la raconter.** Les vraies vignettes d'humeur et la mascotte font le travail ; pas de photo stock.
- **Practice what you preach.** Zéro tracking, zéro requête tierce (polices auto-hébergées), site léger.

## Accessibility & Inclusion

WCAG AA : contrastes ≥ 4.5:1 pour le corps de texte, `prefers-reduced-motion` respecté, HTML sémantique, site utilisable sans JavaScript.
