# cozymind.fr

Site vitrine de l'application mobile [CozyMind](https://github.com/EdouardSan) (suivi d'humeur), éditée par SND CAPITAL.

- **Landing** : `index.html`
- **Politique de confidentialité** : `confidentialite.html`
- **Conditions d'utilisation** : `conditions.html`

Site statique sans build : HTML + CSS, polices et images auto-hébergées, aucun tracking.

Hébergé sur **GitHub Pages** (branche `main`, racine) avec le domaine personnalisé **cozymind.fr** (fichier `CNAME`).

Pour mettre à jour : modifier les fichiers (et la date « Dernière mise à jour » des pages légales), commit, push — la page se republie automatiquement.
